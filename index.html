CS3 Hardware — Cambridge IGCSE Computer Science Study Guide

3.1 The Role of the CPU

The central processing unit (CPU) is one of the fundamental parts of a computer. It is where all the data and instructions are processed. The CPU acts like the brain of the computer system.

All computers have a form of CPU. In personal computers (PCs) and laptops, it is a separate component. In household devices such as washing machines, traffic lights, and digital alarm clocks, a similar but smaller component called a microprocessor is used. A microprocessor performs a similar role to a CPU but on a smaller scale, processing a much more limited set of instructions.

A microprocessor is often built into a system designed to perform a very specific task. This type of system is called an embedded system. Examples include traffic lights, washing machines, and digital alarm clocks.

When an instruction is processed by a computer, the method used is called the fetch-decode-execute cycle. The CPU operates using the Von Neumann architecture, which is one of the most common types of modern computer architecture.

The Fetch-Decode-Execute Cycle

The cycle has three stages that repeat continuously:

  1. Fetch — The next instruction is fetched from RAM into the CPU
  2. Decode — The instruction is decoded (interpreted) within the CPU by the control unit
  3. Execute — The instruction is executed (carried out) by the CPU

3.2 The Fetch Stage

Data and instructions are given to the computer through input devices and stored in RAM (random access memory). When they need to be processed, they must be brought from RAM into the CPU.

The fetch stage involves the following steps:

  1. The program counter (PC) stores the address of the next instruction to be processed. This address is a location within RAM.
  2. The address stored in the PC is sent to the memory address register (MAR) via the address bus.
  3. The MAR sends the address to RAM using the address bus to locate the instruction.
  4. The data stored at that RAM location (the instruction) is sent to the memory data register (MDR) via the data bus.
  5. The MDR sends the instruction to the current instruction register (CIR) using the data bus.
  6. The CIR is part of the control unit (CU), which is responsible for the next stage — the decode stage.

3.3 The Decode Stage

The decode stage begins when the instruction is received by the control unit (CU). The CU decodes the instruction so that the CPU can understand what is required to execute it.

To decode an instruction, the CU uses an instruction set — a set of all the commands that are understood and can be processed by the CPU. These commands are in machine code. Once the instruction is decoded using the instruction set, it can be executed.

3.4 The Execute Stage

The execute stage is when the actions required for the instruction are carried out. This is likely to involve mathematical and logical calculations.

  • If calculations are required, the data is sent to the arithmetic logic unit (ALU), the component within the CPU responsible for all calculations.
  • The ALU has a special register called the accumulator (ACC) that stores interim values created during calculations.
  • Once calculations are complete, the actions for the instruction are performed (e.g. a file is opened or a letter is displayed).

The CU acts as a conductor, sending signals via the control bus to all components within the CPU to coordinate their roles in the fetch-decode-execute cycle.

3.5 Factors That Affect CPU Performance

The performance of a CPU refers to how quickly it can process instructions. The more instructions processed per second, the higher the performance. There are three main factors that affect CPU performance:

Number of Cores

  • A single core contains all the components needed to perform the fetch-decode-execute cycle.
  • A single-core CPU can perform one fetch-decode-execute cycle at a time.
  • A dual-core processor has two cores and can perform two cycles simultaneously.
  • A quad-core processor has four cores and can perform four cycles simultaneously.
  • More cores allow a computer to multitask — processing more than one instruction at a time.
  • However, adding more cores does not always proportionally increase performance.

Clock Speed

  • The CPU contains an internal clock that controls the speed at which instructions are processed.
  • Clock speed is measured in hertz (Hz). A CPU with a clock speed of 1 Hz can process one instruction per second.
  • Modern computers have clock speeds measured in gigahertz (GHz). A 2 GHz CPU can process 2 billion instructions per second.
  • If a computer has two cores, each core can process 2 billion instructions per second.
  • It is possible to change the speed of a CPU using overclocking.

Cache Size

  • The cache is a type of data storage within the CPU.
  • Instructions and data that the computer uses most frequently can be stored in the cache.
  • Accessing data from the cache is quicker than fetching from RAM.
  • A larger cache means more frequently used data can be stored, reducing the need to access RAM and improving performance.
  • However, if the cache is too large, it can take longer to search through it, potentially having a negative effect on performance.

3.6 Input and Output Devices

Input Devices

An input device is any device that allows data to be entered into a computer system. This data could take many forms including text, images, and sound.

Common examples of input devices:

  • Barcode scanner — Scans barcodes to read the data stored within them (e.g. supermarket pricing)
  • Digital camera — Captures images and video as digital data
  • Keyboard — Allows text and commands to be entered as character data
  • Microphone — Captures sound as audio data
  • Optical mouse — Detects movement and button clicks for cursor control
  • QR code scanner — Reads QR codes to obtain embedded data
  • Scanner (2D and 3D) — Captures printed documents or physical objects as digital data
  • Touch screen — Allows direct interaction through screen contact; three types: resistive, capacitive, and infra-red

Output Devices

An output device is any device that allows the result of data processing to be seen or heard.

Common examples of output devices:

  • Actuator — Outputs an action, often movement, to control another device (e.g. turning a light on/off in an automated system)
  • Digital light processing (DLP) projector — Projects images onto a surface using light
  • Inkjet printer — Produces printed output by spraying ink onto paper
  • Laser printer — Produces printed output using laser and toner technology
  • Light emitting diode (LED) screen — Displays visual output using LED technology
  • Liquid crystal display (LCD) projector — Projects images using LCD technology
  • Liquid crystal display (LCD) screen — Displays visual output using LCD technology
  • Speaker — Produces audio output
  • 3D printer — Creates three-dimensional physical objects from digital designs

3.7 Sensors

A sensor is a type of input device used in an automated system to capture different types of data from the surrounding environment. Sensors capture analogue data that can be processed and analysed by a computer system. They are normally set to capture data at given time intervals.

3.8 Data Storage — Primary Storage

Data in a computer system needs to be stored either temporarily (while being processed) or permanently (for future use). There are two main categories: primary storage and secondary storage.

Primary storage is directly accessed by the CPU. There are two main types: RAM and ROM.

RAM (Random Access Memory)

  • Volatile storage — contents are lost when power is turned off (also called temporary storage)
  • Stores data and programs that are currently in use by the computer
  • Contents are constantly being changed as data is processed by the CPU
  • It is possible to increase the amount of RAM by adding further RAM components

ROM (Read Only Memory)

  • Non-volatile storage — contents are retained even when power is removed (also called permanent storage)
  • Stores programs that initially boot the computer, such as the bootstrap and the BIOS
  • Contents are fixed and do not normally change; reprogramming is possible but complex and rarely attempted
  • It is not easy to alter the amount of ROM available in a computer system

3.9 Data Storage — Secondary Storage

Secondary storage is a category of storage that is not directly accessed by the CPU. Data and instructions must be sent from secondary storage into primary storage to be processed. Secondary storage is non-volatile. There are three main types:

Magnetic Storage

  • Relies on the properties of magnetism to store data
  • Uses circular plates called platters that spin to allow data to be read and written
  • Platters are separated into tracks and sectors
  • A read/write head moves across the platters to read or write data
  • Uses an electromagnet to magnetise dots on each platter: magnetised = binary 1, demagnetised = binary 0
  • Each platter has billions of magnetised dots
  • Example: hard disk drive (HDD)

Optical Storage

  • Uses lasers to read and write data to and from a circular disk
  • The disk spins and a read/write head moves across the surface
  • To write data, a laser burns pits into the surface of the disk
  • The surface between each pit is called a land
  • Pits are organised in a spiral track starting from the centre of the disk
  • A laser reads the pits and lands to obtain the stored data
  • Examples: CD, DVD, Blu-ray
  • Mostly used today to archive data or physically distribute files

Solid-State Storage

  • Has no moving parts, making it more durable than magnetic or optical storage
  • Created using semiconductor chips; sometimes known as flash memory
  • Contains cells and transistors laid out in a grid
  • Transistors can be wired in two ways: NOR flash (parallel) and NAND flash (series)
  • Each transistor intersection has a control gate and a floating gate
  • When first created, all transistors are set to binary 1; storing data converts them to binary 0
  • Examples: solid state drive (SSD), USB flash memory drive (USB stick, memory stick, thumb drive)

3.10 Virtual Memory

Virtual memory is a type of memory created for temporary use as an extension to RAM. It is created by partitioning a section of a hard drive component to act as extra RAM.

How Virtual Memory Works

  1. When RAM becomes full, the computer transfers data that is not immediately required to the virtual memory on the hard drive
  2. Data is transferred in structures called pages
  3. Pages of data are held in virtual memory until they are needed again
  4. When the pages are required, they are sent back to RAM for processing
  5. This process frees up room in RAM for immediate data that is being processed

If the RAM became full and the computer did not have virtual memory, it could crash as it may not be able to complete the current task.

3.11 Cloud Storage

Cloud storage is when data is stored remotely on servers that are owned and maintained by a third party, and accessed using the internet. When data is stored within buildings and hardware owned by the individual or business, this is known as storing data locally. When data is stored in hardware owned by a third party and accessed using the internet, this is known as storing data remotely.

Cloud storage companies set up very large buildings housing thousands of computer servers, maintained 24 hours a day. Companies pay a fee to store their data on these servers.

Cloud Storage vs Local Storage

Aspect Cloud Storage Local Storage
Cost No need to pay for hardware to store data Must purchase hardware; costs can be high for large amounts of data
Security Third party responsible; risk if they fail to protect data properly You control security; can regularly check and maintain storage
Accessibility Access from anywhere with internet; relies on internet connection quality Available at all times without internet; local access only
Scalability Can increase or decrease storage space easily May have redundant hardware that is paid for but not used

3.12 Network Hardware

When two or more devices are connected, this is called a network. Basic hardware devices required to create a network are a network interface card (NIC), a router, and transmission media.

Network Interface Card (NIC)

  • A piece of hardware within your computer or device
  • May be wired or wireless (most modern NICs are wireless — WNICs)
  • Each NIC is given a media access control (MAC) address to identify a device on a network
  • MAC address is assigned by the manufacturer and never normally changed
  • Made up of two parts: the manufacturer's ID code and the serial ID code for the device
  • Represented as hexadecimal with six pairs of numbers (e.g. 34:4D:EA:89:75:B2)
  • When data is transmitted, the MAC address is sent with the data to identify the source device

Router

  • A hardware device that reads each data packet it receives
  • Reads data packets to find the destination of the data
  • Uses the MAC address for devices on the same local network
  • Uses the IP address to forward data to devices on the internet or different networks
  • Assigns IP addresses to devices connected to it

IP Addresses

An IP address is a unique address used to locate a device on a network. It is assigned by the network (usually the router), unlike a MAC address which is assigned by the manufacturer.

IPv4:

  • Created in 1983, uses 32-bit addresses
  • Separated by full stops (e.g. 12.244.233.165)
  • Running out due to the increasing number of devices worldwide

IPv6:

  • Created to provide more available addresses
  • Uses 128-bit addresses and can contain hexadecimal characters
  • Separated by colons (e.g. 2001:0db8:0000:0000:0000:ff00:0042:7879)

Static vs Dynamic IP Addresses:

  • Dynamic — Changes each time the device connects to a network; most devices use dynamic addresses
  • Static — Remains the same every time the device connects; provided by the Internet Service Provider (ISP)

Practice Questions

Question CS3.01

Where is data stored before it is fetched into the CPU?

Answer: Data is stored in RAM (random access memory) before it is fetched into the CPU.

Question CS3.02

Which component in the CPU is responsible for making sure the fetch-decode-execute cycle is performed correctly?

Answer: The control unit (CU) is responsible for coordinating the fetch-decode-execute cycle by sending signals via the control bus to all components within the CPU.

Question CS3.03

What is the role of a bus in a computer system?

Answer: A bus is a communication pathway that carries data, addresses, or control signals between components within the CPU and between the CPU and memory. The three main buses are the address bus, data bus, and control bus.

Question CS3.04

Why does the ALU need the accumulator (ACC)? What would happen without it?

Answer: The ALU needs the accumulator to store interim values that are created during calculations. Without it, the ALU would not be able to store partial results while performing multi-step calculations, and it would need to constantly access RAM, which would significantly slow down processing.

Question CS3.05

Describe the steps involved in the fetch stage of the fetch-decode-execute cycle.

Answer: (1) The program counter (PC) holds the address of the next instruction. (2) This address is copied to the memory address register (MAR) via the address bus. (3) The MAR sends the address to RAM using the address bus. (4) The instruction at that RAM location is sent to the memory data register (MDR) via the data bus. (5) The MDR forwards the instruction to the current instruction register (CIR). (6) The PC is incremented to point to the next instruction.

Question CS3.06

Which CPU can process more instructions at the same time: a quad core or a dual core?

Answer: A quad-core CPU can process more instructions at the same time because it has four cores, each capable of performing a separate fetch-decode-execute cycle simultaneously, compared to only two cores in a dual-core processor.

Question CS3.07

How many instructions per second can a dual-core 2.4 GHz CPU process?

Answer: A dual-core 2.4 GHz CPU can process 4.8 billion instructions per second (2.4 billion per core x 2 cores).

Question CS3.08

Explain why a larger cache can improve the performance of a CPU.

Answer: A larger cache can store more frequently used instructions and data within the CPU. This means the CPU does not need to fetch data from the slower RAM as often, reducing access times and improving overall processing speed.

Question CS3.09

Is a sensor an example of an input device or an output device? Explain your answer.

Answer: A sensor is an example of an input device because it captures data from the surrounding environment and sends it into the computer system for processing. It inputs analogue data such as temperature, light levels, or pressure readings.

Question CS3.10

Name five different types of sensor and give an application for each.

Answer: (1) Temperature sensor — used in air conditioning systems to maintain room temperature. (2) Light sensor — used in streetlights to automatically turn on when it gets dark. (3) Pressure sensor — used in security systems to detect opened windows or doors. (4) Humidity sensor — used in greenhouses to monitor moisture levels for optimal crop growth. (5) Infra-red sensor — used in security systems to detect intruders by capturing their infra-red radiation.

Question CS3.11

State two differences between RAM and ROM.

Answer: (1) RAM is volatile (loses contents when power is off) while ROM is non-volatile (retains contents without power). (2) RAM stores data and programs currently in use that constantly change, while ROM stores fixed boot-up programs like the BIOS that do not normally change.

Question CS3.12

Identify the three main types of secondary storage and give one example of each.

Answer: (1) Magnetic storage — e.g. hard disk drive (HDD). (2) Optical storage — e.g. CD, DVD, or Blu-ray. (3) Solid-state storage — e.g. solid state drive (SSD) or USB flash memory drive.

Question CS3.13

Describe how data is stored on optical storage.

Answer: Optical storage uses lasers to read and write data on a circular disk. To write data, a laser burns pits into the surface of the disk. The surface between each pit is called a land. These pits and lands are organised in a spiral track starting from the centre of the disk. A laser reads the pattern of pits and lands to retrieve the stored data. The disk spins and a read/write head moves across the surface.

Question CS3.14

Explain how virtual memory works and why it is needed.

Answer: Virtual memory is created by partitioning a section of the hard drive to act as extra RAM. When RAM becomes full, the computer transfers pages of data that are not immediately needed to the virtual memory. When these pages are required again, they are sent back to RAM for processing. Virtual memory is needed because without it, if RAM became full, the computer could crash as it would be unable to complete the tasks it is working on.

Question CS3.15

Give one advantage and two disadvantages of storing data in cloud storage rather than local storage.

Answer: Advantage: You do not have to pay for the hardware to store the data, reducing costs for businesses. Disadvantages: (1) You are relying on a third party to keep your data safe, and if they fail to do this, your data may be at risk. (2) You need an internet connection to access your data; if the connection fails or is slow, you will not be able to access your data.

Question CS3.16

Identify the name of the component where an instruction is stored immediately before it is fetched into the CPU.

Answer: The instruction is stored in RAM (random access memory) immediately before it is fetched into the CPU.

Question CS3.17

Identify the name of the component that stores the address of the next instruction that will be processed.

Answer: The program counter (PC) stores the address of the next instruction that will be processed.

Question CS3.18

Describe what happens at the decode stage of the fetch-decode-execute cycle.

Answer: During the decode stage, the control unit (CU) receives the instruction from the current instruction register (CIR). The CU then decodes the instruction using the instruction set — a set of all the machine code commands that the CPU can understand. This determines what actions need to be performed to execute the instruction. Once decoded, the instruction is ready to be executed.

Question CS3.19

A student replaces a 2 GHz single-core processor with a 3.4 GHz dual-core processor. Explain why the performance of the new CPU would be better.

Answer: The new CPU has a higher clock speed (3.4 GHz vs 2 GHz), meaning each core can process more instructions per second. Additionally, the new CPU has two cores instead of one, so it can perform two fetch-decode-execute cycles simultaneously. This means it can multitask and process more instructions overall, significantly improving performance.

Question CS3.20

What is the difference between a MAC address and an IP address?

Answer: A MAC address is assigned by the manufacturer of the network interface card and is permanent — it never normally changes. An IP address is assigned by the network (usually the router) and can change. MAC addresses are used to identify devices on a local network, while IP addresses are used to identify and locate devices across networks and the internet. MAC addresses are represented in hexadecimal (e.g. 34:4D:EA:89:75:B2) while IP addresses use decimal (IPv4) or hexadecimal (IPv6) notation.

Question CS3.21

Describe the structure of an IPv4 address and explain why IPv6 was created.

Answer: An IPv4 address uses 32 bits to create a numerical address separated by full stops (e.g. 12.244.233.165). IPv6 was created because as more and more devices started connecting to networks, the number of available IPv4 addresses was rapidly declining. Since each IP address must be unique, IPv6 uses 128 bits and can contain hexadecimal characters, creating vastly more possible addresses to accommodate the growing number of devices worldwide.

Question CS3.22

Give the most appropriate sensor for each scenario: (a) monitoring pollution in a river, (b) counting competitors finishing a race, (c) detecting a person approaching an automatic door.

Answer: (a) A pH sensor — to measure the pH level of the water and detect pollution. (b) A pressure sensor or infra-red sensor — to detect when a competitor crosses the finish line. (c) A proximity sensor or infra-red sensor — to detect when a person is approaching the door and trigger it to open.

Question CS3.23

Explain the difference between primary storage and secondary storage.

Answer: Primary storage is directly accessed by the CPU and includes RAM (volatile) and ROM (non-volatile). Secondary storage is not directly accessed by the CPU — data must be transferred to primary storage first before it can be processed. Secondary storage is always non-volatile and includes magnetic, optical, and solid-state storage types. Primary storage is generally faster but smaller in capacity, while secondary storage is slower but offers larger storage capacity.

Question CS3.24

Describe how data is stored on a hard disk drive (magnetic storage).

Answer: A hard disk drive uses circular plates called platters that spin. The platters are separated into tracks and sectors. A read/write head moves across the platters to read or write data. An electromagnet magnetises dots on each platter to store data — if a dot is magnetised it stores binary value 1, and if it is demagnetised it stores binary value 0. Each platter has billions of these magnetised dots.

Question CS3.25

Explain why solid-state storage was developed and how it differs from magnetic storage.

Answer: Solid-state storage was developed because hard disk drives have moving parts, making them vulnerable to wear and damage if dropped — a significant disadvantage for portable devices. Solid-state storage has no moving parts, making it more durable and reliable. It uses semiconductor chips and flash memory with cells and transistors arranged in a grid, whereas magnetic storage uses spinning platters and electromagnetic read/write heads. Solid-state storage is generally faster and more resistant to physical damage than magnetic storage.

Key Formulas and Concepts

  1. Clock speed is measured in hertz (Hz); 1 GHz = 1 billion instructions per second per core
  2. Total processing power = clock speed x number of cores (e.g. dual-core 2.4 GHz = 4.8 billion instructions per second)
  3. IPv4 uses 32-bit addresses (approximately 4.3 billion unique addresses); IPv6 uses 128-bit addresses (approximately 340 undecillion unique addresses)
  4. The three buses in a CPU: address bus (carries memory addresses), data bus (carries data), control bus (carries control signals)
  5. The fetch-decode-execute cycle sequence: PC → MAR → (address bus to RAM) → MDR → CIR → CU decodes → ALU executes
  6. Volatile storage (RAM) loses data without power; non-volatile storage (ROM, secondary storage) retains data without power
  7. Virtual memory extends RAM capacity by using a partitioned section of the hard drive
  8. MAC address format: six pairs of hexadecimal digits (e.g. 34:4D:EA:89:75:B2) — 48 bits total
  9. Three factors affecting CPU performance: number of cores, clock speed, cache size
  10. Three types of secondary storage: magnetic (HDD), optical (CD/DVD/Blu-ray), solid-state (SSD/USB)

Exam Focus Priorities

  1. Be able to describe the complete fetch-decode-execute cycle, naming all registers (PC, MAR, MDR, CIR) and buses (address, data, control) involved at each stage
  2. Know the roles of all CPU components: CU (decodes instructions, coordinates), ALU (performs calculations), ACC (stores interim values), and all registers
  3. Understand the three factors that affect CPU performance (cores, clock speed, cache) and be able to explain how each one improves performance
  4. Distinguish clearly between RAM (volatile, temporary, changeable) and ROM (non-volatile, permanent, fixed) and know what each stores
  5. Be able to describe how each type of secondary storage works: magnetic (platters, tracks, sectors, read/write head), optical (laser, pits, lands, spiral track), solid-state (semiconductor chips, transistors, flash memory)
  6. Know all sensor types from the syllabus and be able to match the correct sensor to a given scenario
  7. Understand the difference between input devices and output devices, and know all examples from the syllabus
  8. Be able to explain how virtual memory works, why it is needed, and the role of pages in the process
  9. Know the advantages and disadvantages of cloud storage vs local storage
  10. Understand network hardware: NIC, MAC address, router, IP address (IPv4 vs IPv6, static vs dynamic)
